# 月报图片生成

这是一个用于制作儿童成长月报海报的本地项目，核心功能是根据 9 张儿童照片和文案配置，自动排版并生成精美的 A4 竖版海报。

## 项目介绍

本仓库主要聚焦于“成长月报海报自动生成”，使用 Python + Pillow 进行传统图层合成，不依赖 AI 绘图模型。

它的工作流程通常包括：

- 读取儿童原始照片
- 读取 JSON 配置（姓名、月份、标题、文案、照片优先级等）
- 进行照片裁切、缩放、旋转、边框和排版
- 将文字、装饰、背景和照片组合成月报海报
- 导出 PNG 成品和渲染报告

该项目适合用于：

- 儿童成长月报
- 亲子记录册封面/内页
- 纪念日或月度回顾海报
- 批量生成多位儿童的统一风格海报

## 目录说明

- `poster_generator/`：核心海报生成脚本与模板配置
- `日志去水印/`：本地日志/去水印处理文件夹，通常用于辅助资料处理

## 主要特性

- 自动读取照片和文案配置
- 统一模板风格输出
- 支持多张照片组合排版
- 输出 PNG 以及渲染说明 JSON
- 适合本地离线生成，不依赖外部在线图片服务

## 注意事项

为了保持仓库整洁并避免上传无用数据，本项目中请勿提交：

- 原始照片素材
- 生成后的 PNG 输出
- 中间缓存文件和日志文件
- 本地临时目录内容

这些内容应保留在本地工作目录中，仅保留脚本、配置和模板等必要代码文件。
